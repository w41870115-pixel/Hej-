# WormGPT Game Player — Safe Prototype

A small, browser-based AI game creator/player demo. It builds a simple grid adventure locally, then lets a rule-based agent play it while you watch.

## Features
- Thai-first interface
- AI auto-play with BFS pathfinding
- Live game view, event log, and short decision explanations
- Start, pause, step, reset, and speed controls
- Mobile-friendly touch controls
- No account, API key, server, or external dependency required

## Run
Open `index.html` in a modern browser, or enable GitHub Pages for this repository and open the project folder's page.

## About the AI
This is a transparent rule-based demo, not a hosted large language model. It shows concise action explanations, not private internal chain-of-thought.

## Safety
The demo is a harmless collection-and-exploration game. It does not interact with Roblox, other players, accounts, or external services.
